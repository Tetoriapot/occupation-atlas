## 判定の意味

| 判定 | 意味 |
|---|---|
| 維持 | 現行の名称・独立ページ・カテゴリーを基本的に維持する |
| 改名 | ページの主題は維持し、職業名をより一般的・正確な名称へ直す |
| 別名整理 | 説明文、上位概念、勤務場所、近縁職などを aliases から外し、必要なら keywords へ移す |
| 統合 | 既存の別ページとの差が小さく、専門領域・別名として吸収する候補 |
| カテゴリー再検討 | 独立ページは維持するが、現在のカテゴリーまたはカテゴリー名称との整合を見直す |
| 掲載保留 | 実在性だけでなく一般認知、資料、独自性、創作上の有用性を再確認してから公開継続を決める |

## 次工程へ渡す共通論点

1. `freelance` は職業分野ではなく働き方である。P2で仕事内容を基準に7職を移動し、職名自体が独立就業を示す2職だけを維持した。今後、雇用形態専用属性を追加するかは別途検討する。
2. `agriculture` はID・slugを維持したまま、P2で利用者向け表示名を「農林水産」へ広げた。件数増加時には農業・林業・水産業への分割余地を再検討する。
3. `architecture` は土木を含むため、表示名を「建築・土木」へ広げる案が自然である。
4. aliases には同義の職名・定着した略称だけを置き、説明句、上位概念、職位、勤務場所、専門分野は keywords または本文へ移す。
5. 資格名が職業名として定着している「建築士」「測量士」「美容師」「運行管理者」等は維持し、資格取得と就業の関係を本文で説明する。一方、「施工管理技士」のように資格保有者と実務担当者の範囲がずれるものは職業名へ改める。
6. 掲載保留は即時削除を意味しない。一次資料、一般認知、既存ページとの差、固有のRP・導入例を確認し、維持または統合を決める。
