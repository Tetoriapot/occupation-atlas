# 人気職業ランキング受け入れ監査

- 監査日・閲覧日: 2026-07-18
- 参照元: [13歳のハローワーク「人気職業ランキング」](https://13hw.com/jobapps/ranking.html)
- 参照ランキング: 2026年4月（集計期間: 2026-04-01〜2026-04-30）
- 突合対象: 追加前の現行職業データ200件と、参照ランキング100項目
- 実装状況: 新規追加40件を14件・12件・12件の3バッチと補完2件で反映し、2026-07-18時点で合計240件

参照元の説明によると、このランキングは集計期間内のアクセス数・ユーザー数などを基に順位付けされたものである。本監査では利用者の関心を示す**需要シグナル**としてのみ利用し、公式な職業分類、就業者数、社会的重要度、当サイトの掲載順位とはみなさない。原表記には参照元の名称を記録したが、説明文は転載せず、当サイト独自の編集基準で正規名称と掲載可否を判断した。

## 判定基準

| 判定 | 扱い |
|---|---|
| 既存 | 現行の独立ページで対象範囲を十分に扱える |
| 別名・キーワード | 広義語、通称、勤務先、専門分野などとして既存または追加予定ページの検索導線へ吸収する |
| 新規追加 | 独立した仕事像があり、追加バッチで新しいページを作る |
| 保留 | 職業としての独立性はあるが、カテゴリー方針、法的位置付け、一次資料または掲載優先度の追加確認が必要 |
| 掲載しない | 勤務先・業界名にとどまる、既存職との差が小さい、または現時点の図鑑方針では独立ページを維持しにくい |

新規追加は、次の5観点で選別した。ランキング入りだけを理由に採用せず、文章量を満たすための水増しもしない。

1. **認知度**: 現代日本で一般に通じ、利用者が職業名として検索しやすい。
2. **独立性**: 既存職と責任範囲、工程、資格、権限または勤務環境が明確に異なる。
3. **創作価値**: 固有の知識、RP、立ち入り場所、事件への接点やシナリオ導入を書き分けられる。
4. **一次資料**: 行政機関、資格団体、職能団体などから仕事内容・制度を確認できる見込みがある。
5. **カテゴリー適合性**: 現行カテゴリーへ無理なく配置でき、関連職業への導線も作れる。

## 追加バッチ編成

追加優先度は参照ランキングの順位だけで決めず、認知度、既存職との差、創作上の書き分け、一次資料の確認可能性を合わせて判断した。優先度Aをバッチ1、優先度Bをバッチ2、優先度Cをバッチ3として12〜15件ずつ段階追加し、当初保留した2件は対象範囲とカテゴリーを再整理したうえで補完追加した。したがって、実装順は**14件／12件／12件＋補完2件**であり、補完2件を既存バッチへ遡って含めていない。

## 実装時の注意

- 新規ページの `aliases` には同じ人物を指せる一般的な別名だけを置き、ランキングの広義語・勤務先表現は原則 `keywords` に置く。
- 資格名を正規名称に使う場合は、資格が職業名としても一般に定着しているか、名称独占・業務独占・任用要件等の違いを一次資料で確認する。
- 同一バッチで、追加先カテゴリーの既存ページも仕事内容、一日の流れ、RP、適性、関連職業、シナリオシチュエーション、出典まで再確認する。
- 各バッチ完了時にデータ検証、別名を含む検索、カテゴリー・複数条件検索、関連職業、metadata、主要ページ、lint、型チェック、テスト、production buildを確認する。
- 保留・掲載しない項目も原表記を監査記録に残し、今後ランキングやカテゴリー構成が変わった際に再評価できるようにする。
